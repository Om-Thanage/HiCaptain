# Domain language

| Term | Meaning |
| --- | --- |
| User | One person with one login identity, identified by a unique email address. |
| Organization | A workspace whose projects and people belong together. |
| Membership | A user's place in one organization. It carries one or more roles in that organization. |
| Role | A permission group assigned through membership: Admin, Project Manager, Developer, or Client. A user's roles can differ between organizations. |
| Organization owner | The user who creates an organization. The owner starts with the Admin role. |
| Invitation | A time-limited offer to join one organization with specified roles, addressed to one email address. |
| Active organization | The organization the user is working in for the current session. |
